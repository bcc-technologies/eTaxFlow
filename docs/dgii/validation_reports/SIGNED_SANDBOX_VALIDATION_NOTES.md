# Signed Tipo 31 Sandbox Validation Notes

## Scope

This report describes the local, offline validation of a Tipo e-CF 31 unsigned
draft after applying the explicit Phase 016 test-only XMLDSig sandbox. It is
not DGII certification evidence and must not be submitted.

## Interpretation

The synthetic signature verifies against the ephemeral self-signed test
certificate generated by the local sandbox. Local XSD validation accepts the
Signature through the source XSD's `xs:any` particle. This proves only that the
local prototype can sign and validate its own test artifact. It does not prove
certificate trust, DGII profile compatibility, authorization, certification,
or production readiness.

The local XSD still requires the documented experimental in-memory stub for
`IndicadorServicioTodoIncluidoType`. That limitation is reported separately
from instance errors and is not official DGII schema content.

## Safety boundary

- No DGII endpoint or live network transport was used.
- No TrackId was created.
- No production certificate or private key was used.
- Test-only key/certificate files were temporary and removed.
- The unsigned draft builder remains unsigned; sandbox signing is a separate
  explicit test operation.
- `NOT_DGII_COMPLIANT` remains the application status.
